NEXUS AI Personal + Business Dashboard — PWA v1.1

Features:
- Dashboard with Personal Mode and Business Mode
- A.K Communication business profile
- Tasks with mode and due date
- Customer records
- Income/expense records and running totals
- Agent team role dashboard
- Approval Center with approve/reject status
- Local browser storage and service-worker offline cache

IMPORTANT LIMITATIONS:
- This is a local-first starter PWA, not a fully connected AI system.
- Real AI model, WhatsApp/email, live web research, cloud sync, push notifications and computer automation are NOT connected.
- Approval marks a request approved/rejected in this app only; it does not execute the external action.
- Data is stored in the browser on this device. Clearing browser data may erase it. Export/backup is not included yet.
- Financial totals are simple manual records, not audited accounting or tax reports.

INSTALL:
1. Upload all files from this folder to an HTTPS static host (GitHub Pages / Cloudflare Pages).
2. Open hosted URL in Android Chrome.
3. Chrome menu (⋮) > Install app / Add to Home screen.
4. After first load, basic pages can work offline.

Do not open index.html directly from ZIP/Downloads expecting installability. PWA service workers require HTTPS or localhost.
